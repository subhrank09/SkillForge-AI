# SkillForge AI 🚀

> **A Full-Stack AI-Powered Personalized Learning Platform**

SkillForge AI is an interactive educational platform that uses Artificial Intelligence to generate personalized learning roadmaps. Unlike traditional LMS platforms with static lists, SkillForge visualizes knowledge as an **interactive dependency graph**, allowing users to unlock nodes, take quizzes, and track progress through a gamified interface.

## 🏗 System Architecture

The project follows a **Monorepo** architecture to ensure unified version control and rapid development.

### **Tech Stack**

**Frontend (The Interactive Core):**
* **Framework:** React.js (Vite) for fast HMR and bundling.
* **Visualization:** React Flow (Interactive Node Graph).
* **Animations:** Framer Motion for UI transitions.
* **Styling:** Tailwind CSS + Lucide Icons.
* **State Management:** React Context API.

**Backend (The Brain):**
* **Runtime:** Node.js.
* **Framework:** Express.js (REST API).
* **AI Integration:** OpenAI API / Gemini (Generative AI for JSON Curriculum).
* **Validation:** Zod (Strict schema validation for AI outputs).

**Database:**
* **Primary DB:** MongoDB Atlas (NoSQL).
* **ODM:** Mongoose.
